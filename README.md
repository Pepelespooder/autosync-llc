# AutoSync LLC website

A static website for AutoSync LLC. It uses plain HTML, CSS, and a small JavaScript file, so GitHub Pages can serve it directly from the repository root.

## Local preview

Open `index.html` in a browser, or run a local static server from this directory.

## GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
